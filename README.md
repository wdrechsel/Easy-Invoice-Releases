# Easy Invoice – Downloads

Easy Invoice erstellt elektronische Rechnungen nach EN 16931 (XRechnung und ZUGFeRD)
für Windows, macOS und Linux.

Dieses Repository enthält nur die fertigen Installer und die Update-Informationen der
App. Der Quellcode ist nicht öffentlich.

## Installieren

Die aktuelle Version finden Sie unter
[Releases → Latest](https://github.com/wdrechsel/Easy-Invoice-Releases/releases/latest):

| System | Datei |
| --- | --- |
| Windows | `EasyInvoice_<Version>_Windows_x64_setup.exe` oder `…_Windows_x64.msi` |
| macOS (Apple Silicon, M1 und neuer) | `EasyInvoice_<Version>_macOS_AppleSilicon.dmg` |
| macOS (Intel) | `EasyInvoice_<Version>_macOS_Intel.dmg` |
| Linux | `EasyInvoice_<Version>_Linux_x64.AppImage`, `.deb` oder `.rpm` |

Die `.sig`-Dateien und `latest.json` nutzt die App für automatische Updates; Sie
brauchen sie nicht herunterzuladen.

## Updates

Die App prüft beim Start, ob eine neue Version vorliegt, und bietet sie zur
Installation an. Jedes Update ist signiert und wird vor der Installation geprüft.
